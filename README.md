# dnorton/homebrew-tap

Homebrew packages for my tools.

```bash
brew install dnorton/tap/rabbit
```

| Package | What it is |
|---|---|
| [rabbit](https://github.com/dnorton/rabbit-pace) | Running pace calculator with split tables, negative splits and treadmill mph |

Casks in `Casks/` are generated by [GoReleaser](https://goreleaser.com) when a
project is released. Don't edit them by hand; changes are overwritten on the
next release.
